# How Do I Check My Pending Expenses?
Ask the assistant for your pending total or list, or open the My Expenses page. The assistant uses only records visible to your authenticated account.

# How Do I Check a Category Limit?
Ask for the limit for a category such as Travel. The assistant reads configured category limits from Masroof.

# Can the Assistant Approve an Expense?
No. The assistant is read-only and cannot submit, approve, reject, or edit expense records.

# What If No Budget Is Available?
A department may not have a budget configured for the requested month. The assistant should report that the budget is not configured rather than assume a value.
